Неделя 19 · U5 §1

1. Población, muestra и типы переменных

  • Población (генеральная совокупность) — все объекты исследования; muestra (выборка) — часть совокупности, которую реально опросили; tamaño muestral (N) — объём выборки.
  • Variable cualitativa — выражается словами, а не числами (цвет глаз, профессия).
  • Variable cuantitativa discreta — принимает отдельные (обычно целые) значения: число детей в семье, число ошибок в тесте.
  • Variable cuantitativa continua — может принимать любые промежуточные значения на отрезке (рост, вес, зарплата) и группируется в интервалы [a, b). Для расчётов каждый интервал заменяют его серединой — marca de clase: xi = (a + b)/2.

Неделя 21 · U5 §3.1

3. Parámetros de centralización y posición

x̄ = Σ(xi · fi)/NMedia aritmética (среднее)
Mo = xi с наибольшим fiModa (самое частое значение)
Me: первое xi, где Fi ≥ N/2Mediana (делит выборку 50% / 50%)

Квартили (Cuartiles Q₁, Q₂, Q₃) делят упорядоченный ряд на четыре равные части по 25%: для Q₁ ищем в столбце накопленных частот Fi первое значение ≥ N/4 (25%), Q₂ = Me (50%), а для Q₃ — первое Fi ≥ 3N/4 (75%). Если Fi в точности равно порогу, берут полусумму xi и xi+1.

Неделя 22 · U5 §3.2

4. Parámetros de dispersión (разброс данных)

Показывают, насколько плотно значения сгруппированы вокруг среднего x̄:

R = xmáx − xmínRango o recorrido (размах)
σ² = Σ(xi² · fi)/N − x̄²Varianza (дисперсия)
σ = √(σ²)Desviación típica (станд. отклонение)
CV = σ/x̄Coeficiente de variación (в долях или %)
Две классические ловушки при расчёте дисперсии σ²
  • В столбце xi² · fi в квадрат возводится только xi, а не fi! Удобнее всего умножить уже готовый столбец (xi · fi) ещё раз на xi.
  • В конце формулы не забудь вычесть квадрат среднего x̄². Дисперсия σ² никогда не может получиться отрицательной!

Неделя 23–24 · U5 §4

5. Estadística bidimensional: корреляция и регрессия

У каждого объекта измеряют сразу две переменные (xi, yi) — например, часы подготовки X и оценку на экзамене Y. Точки на плоскости образуют облако точек (nube de puntos / diagrama de dispersión).

σxy = Σ(xi · yi)/N − x̄ · ȳCovarianza (ковариация)
r = σxy/σx · σyCorrelación de Pearson (−1 ≤ r ≤ 1)
y − ȳ = σxy/σx² (x − x̄)Recta de regresión de Y sobre X
  • Знак σxy и r: если r > 0 — связь прямая (correlación directa / positiva: растёт X → растёт Y); если r < 0 — обратная (inversa / negativa).
  • Сила связи: чем ближе |r| к 1 (например, 0,92 или −0,95), тем сильнее линейная зависимость (fuerte) и тем надёжнее прогноз по прямой регрессии. Если r ≈ 0 — связи нет.
Ejemplo resuelto · прогноз по прямой регрессии

По данным 5 наблюдений получено: x̄ = 4, ȳ = 10, σx = 2 (σx² = 4), σy = 5, σxy = 9. Найти коэффициент корреляции r, уравнение прямой регрессии и оценить y при x = 6.

  1. Корреляция Пирсона: r = 9 / (2 · 5) = 0,90 (сильная положительная связь, прогноз надёжен).
  2. Прямая регрессии Y по X: y − 10 = (9/4)(x − 4) → y = 2,25x − 9 + 10 → y = 2,25x + 1.
  3. Прогноз для x = 6: y(6) = 2,25 · 6 + 1 = 14,5.

7. Проверь себя

Какова середина интервала (marca de clase) для [20, 30)?
x_i = (20 + 30) / 2 = 25.
В выборке из N = 40 элементов значение встретилось f_i = 6 раз. Чему равны h_i и процент?
h_i = 6 / 40 = 0,15; процент = 15 %.
Найди медиану, моду и среднее ряда: 2, 3, 3, 5, 7.
N = 5: среднее x̄ = (2+3+3+5+7)/5 = 4; мода Mo = 3 (встречается дважды); медиана (центральное 3-е число) Me = 3.
Если Σ(x_i²·f_i)/N = 53, а среднее x̄ = 7, чему равны дисперсия σ² и стандартное отклонение σ?
σ² = 53 − 7² = 53 − 49 = 4; σ = √4 = 2.
Что означает коэффициент корреляции Пирсона r = −0,94?
Между переменными сильная обратная (отрицательная) линейная связь: с ростом X переменная Y убывает.
