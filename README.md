# 🎓 AGS Study Hub 2026–2027 (CPEPA Miguel Hernández · Aeducar)

Приложение для планирования, трекинга прогресса, календаря важных дат и подготовки к экзаменам курса **Acceso a Grado Superior (Curso 2026–2027)**.

🔗 **Открыть приложение (GitHub Pages):** **[https://grachia-m.github.io/ags-study-hub-2627-gm/](https://grachia-m.github.io/ags-study-hub-2627-gm/)**

---

## ✨ Возможности приложения

1. **⚡ План по дням (`План по дням`)** — детальное расписание на каждый день, пересчитанное с **7 ноября 2026 (`07.11.2026`)** до **3 июня 2027 (`03.06.2027`)**, с интерактивными чекбоксами, таймингом, прямыми ссылками на PDF в Google Drive и встроенным ридером конспектов теории (`teoria-fisica-1.html`, `teoria-mates-1.html`, `teoria-espanol-1.html`, `teoria-tecno-1.html`).
2. **🗓️ 30 Недель (`30 Недель`)** — полный мастер-план курса, разбитый по 3 триместрам (`1ª, 2ª, 3ª Evaluación`) с прогресс-барами по каждой неделе и фильтрацией по триместрам.
3. **📅 Календарь и Экспорт (`Календарь и .ICS`)** — интерактивный календарь на **ноябрь 2026 — июнь 2027** (63 официальных события: дедлайны `Actividades de envío`, очные экзамены в Уэске и онлайн-тьютории по расписанию каждого преподавателя) + **скачивание `.ics` файла в 1 клик** для импорта в Google Calendar / Apple Calendar + кнопки **«+ В Google Calendar»** у каждого события.
4. **📚 6 Предметов и Файлы (`Предметы и Файлы`)** — полная база всех 6 предметов и всех папок из обновлённого Google Drive (`curso-grado-superior`), контакты преподавателей, расписание тьюторий, формулы оценки и список исправленных опечаток в официальных PDF (`Erratas`).
5. **📤 Трекер Envíos и Защита от анти-ИИ ловушек (`Actividades de Envío`)** — контроль всех обязательных работ по триместрам с **предупреждениями о скрытом белом тексте (Anti-AI traps)**, обнаруженном в официальных PDF по Математике (U1, U2, U3) и Цифровой компетенции (U1).
6. **🧮 Калькулятор оценок (`Калькулятор оценок`)** — расчёт итогового балла по каждому предмету и триместру с учётом официальных весов (70% очный экзамен + 20–30% Envíos + 0–10% онлайн-тесты) и правила минимального балла `≥ 4.0` на очном экзамене.

