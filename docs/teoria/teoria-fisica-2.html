Неделя 7 · UD2 §1

1. Fuerzas и las 3 Leyes de Newton

Fuerza (F⃗) — векторная мера взаимодействия тел, способная изменить скорость тела или деформировать его. Единица СИ — ньютон (1 N = 1 kg·m/s²). Если на тело действует несколько сил, их складывают векторно (по осям X и Y), получая равнодействующую силу fuerza resultante ΣF⃗.

Закон НьютонаФормулировка и формулаСмысл для задач
1ª Ley · Principio de inerciaЕсли ΣF⃗ = 0, то v⃗ = const (a⃗ = 0).Тело либо покоится (equilibrio estático), либо движется равномерно прямолинейно (MRU).
2ª Ley · Principio fundamentalΣF⃗ = m · a⃗Вдоль оси движения: Fa favor − Fen contra = m · a.
3ª Ley · Acción y reacciónF⃗AB = −F⃗BAСилы равны по модулю, противоположны по направлению, но приложены к разным телам (поэтому не уравновешивают друг друга!).
Неделя 8 · UD2 §2

2. Главные силы механики: Peso, Normal, Rozamiento и Ley de Hooke

P = m · gPeso (вес/сила тяжести, N) — всегда вертикально вниз к центру Земли (g = 9,8 m/s²)
N (Fuerza Normal)Реакция опоры — всегда перпендикулярна (90°) поверхности опоры
Fr = μ · NFuerza de rozamiento (сила трения) — всегда против движения (μ безразмерен)
Fe = k · ΔxLey de Hooke (упругость пружины): k в N/m, удлинение Δx = x − x₀ в метрах
Ловушка: масса ≠ вес, а нормаль N не всегда равна m·g!

Masa (m) измеряется в kg и везде одинакова. Peso (P = m·g) — это сила в ньютонах (N). А сила реакции опоры N находится из баланса сил перпендикулярно поверхности (ΣFy = 0): на горизонтали без наклонных сил N = mg, но на наклонной плоскости N = mg·cos α!

Ejemplo resuelto · Ley de Hooke

Пружина жёсткостью k = 250 N/m имеет длину в ненагруженном состоянии 20 cm. Какова станет её длина, если подвесить груз массой 5 kg?

Сила тяжести груза уравновешивается силой упругости: P = m·g = 5 · 9,8 = 49 N. По закону Гука: Δx = F / k = 49 / 250 = 0,196 m = 19,6 cm. Итоговая длина: 20 + 19,6 = 39,6 cm.

Неделя 9 · UD2 §3

3. Equilibrio estático: тело, подвешенное на двух тросах

Если тело висит неподвижно (en equilibrio), сумма всех сил по обеим осям равна нулю:

ΣFx = 0     и     ΣFy = 0
Ejemplo resuelto · груз на двух тросах

Фонарь массой m = 10 kg висит на двух тросах, образующих с горизонтальным потолком углы α = 30° и β = 60°. Найти силы натяжения T₁ и T₂.

  1. Вес фонаря: P = 10 · 9,8 = 98 N (вниз). Разложим T₁ и T₂ на горизонтальные (cos) и вертикальные (sen) проекции.
  2. Ось X (влево = вправо): T₁·cos 30° = T₂·cos 60° → 0,866 T₁ = 0,5 T₂ → T₂ = 1,732 T₁.
  3. Ось Y (вверх = вниз): T₁·sen 30° + T₂·sen 60° = 98 → 0,5 T₁ + 0,866(1,732 T₁) = 98 → 2 T₁ = 98.
  4. Получаем: T₁ = 49 N и T₂ = 1,732 · 49 = 84,87 N (круче натянутый трос всегда держит большую нагрузку!).
Неделя 10 · UD2 §4

4. Dinámica на горизонтальной плоскости

Если блок тянут по горизонтальному столу силой F под углом α к горизонту:

  • Ось Y (движения вверх-вниз нет, ay = 0): вверх тянет N + F·sen α, вниз P = mg → N = mg − F·sen α (если сила строго горизонтальна, α = 0° и N = mg).
  • Сила трения: Fr = μ · N.
  • Ось X (2-й закон Ньютона): F·cos α − Fr = m · a.
Ejemplo resuelto · ящик на полу

Ящик массой 20 kg тянут по горизонтальному полу горизонтальной силой F = 90 N. Коэффициент трения μ = 0,25. Найти ускорение ящика.

1) N = P = 20 · 9,8 = 196 N. 2) Трение: Fr = 0,25 · 196 = 49 N. 3) По оси X: 90 − 49 = 20 · a → 41 = 20a → a = 2,05 m/s².

Неделя 11 · UD2 §5

5. Plano inclinado (наклонная плоскость)

На наклонной плоскости с углом наклона α оси координат поворачивают вдоль склона: ось X направляют параллельно плоскости (по движению), а ось Y — перпендикулярно плоскости. Тогда раскладывать нужно только вектор силы тяжести P = m·g:

Px = m·g · sen αтянет тело вдоль склона ВНИЗ
Py = m·g · cos α = Nприжимает тело к склону (уравновешивается нормалью N)
Fr = μ · N = μ · m·g · cos αвсегда направлена ПРОТИВ скорости движения
Ejemplo resuelto · спуск по наклонной плоскости

Тело массой m = 5 kg скользит вниз по наклонной плоскости с углом α = 30° и коэффициентом трения μ = 0,2. Найти его ускорение.

  1. Сила тяжести: P = 5 · 9,8 = 49 N. Проекции: Px = 49·sen 30° = 24,5 N; Py = N = 49·cos 30° = 42,44 N.
  2. Сила трения (направлена вверх по склону, против спуска): Fr = μ · N = 0,2 · 42,44 = 8,49 N.
  3. Второй закон Ньютона вдоль склона: Px − Fr = m · a → 24,5 − 8,49 = 5a → a = 16,01 / 5 = 3,20 m/s².
Неделя 12 · UD2 §6

6. Sistemas de cuerpos enlazados y poleas (связанные тела)

Когда два тела m₁ и m₂ связаны нерастяжимой нитью через блок (polea), у них общее по модулю ускорение a и одинаковая сила натяжения нити tensión (T). Такие задачи решаются в два шага:

  1. Записать 2-й закон Ньютона (Fпо ходу − Fпротив = m·a) для каждого тела по отдельности.
  2. Сложить оба уравнения: внутренняя сила натяжения +T и −T сократится, и мы сразу получим общее ускорение системы:
    a = ΣFвнешних (тянущих) − ΣFвнешних (тормозящих)/m₁ + m₂
    Затем подставить найденное a в любое из двух уравнений и найти натяжение нити T.
Ejemplo resuelto · брусок на столе и груз на блоке

На горизонтальном столе с трением μ = 0,2 лежит брусок m₁ = 6 kg, соединённый нитью через блок на краю стола с висящим грузом m₂ = 4 kg. Найти ускорение системы и силу натяжения нити T.

  1. Внешние силы: вниз тянет вес второго груза P₂ = m₂g = 4 · 9,8 = 39,2 N; тормозит трение первого бруска о стол Fr1 = μ·m₁g = 0,2 · 6 · 9,8 = 11,76 N.
  2. Уравнения для каждого тела: для m₁: T − 11,76 = 6a; для m₂: 39,2 − T = 4a.
  3. Складываем уравнения: 39,2 − 11,76 = (6 + 4)a → 27,44 = 10a → a = 2,744 m/s².
  4. Натяжение нити из первого уравнения: T = 11,76 + 6 · 2,744 = 28,22 N.

8. Проверь себя

Машина массой 1200 kg едет по прямому шоссе с постоянной скоростью 90 km/h. Чему равна равнодействующая всех приложенных к ней сил?
Нулю (ΣF = 0)! По 1-му закону Ньютона при постоянной скорости ускорение a = 0, значит тяга двигателя в точности уравновешена силами сопротивления и трения.
Пружина растягивается на 5 cm под действием силы 15 N. Чему равен её коэффициент жёсткости k в СИ?
Переводим 5 cm = 0,05 m. k = F / Δx = 15 / 0,05 = 300 N/m.
Брусок массой 10 kg лежит на наклонной плоскости с углом 30°. Чему равны P_x и сила нормальной реакции N?
P = 10 · 9,8 = 98 N. P_x = 98 · sen 30° = 49 N; N = P_y = 98 · cos 30° ≈ 84,87 N.
На невесомом блоке (машина Атвуда) висят два груза: 3 kg слева и 7 kg справа. С каким ускорением они движутся?
a = (m₂ − m₁)·g / (m₁ + m₂) = (7 − 3)·9,8 / (3 + 7) = 39,2 / 10 = 3,92 m/s².
