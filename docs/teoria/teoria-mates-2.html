1. Lenguaje algebraico, valor numérico и операции с полиномами

Lenguaje algebraico переводит словесные условия на язык букв (incógnitas / variables). Важно точно читать предлоги и порядок слов:

Фраза на испанскомЗаписьПояснение
El doble de un número más tres2x + 3сначала удвоили, потом прибавили 3
El doble de la suma de un número y tres2(x + 3)удвоили всю сумму
La mitad de un número menos su tercera partex/2 − x/3разность долей одного числа
Dos números consecutivosx, x + 1два последовательных целых числа
El cuadrado de la diferencia de dos números(x − y)²квадрат разности (не путать с x² − y²)

Valor numérico и одночлены (monomios)

Valor numérico — число, которое получается при подстановке конкретного значения вместо буквы. Отрицательные числа всегда подставляй в скобках:

Для P(x) = 2x³ − 3x² + 5 при x = −2: P(−2) = 2(−2)³ − 3(−2)² + 5 = 2(−8) − 3(4) + 5 = −16 − 12 + 5 = −23.

У одночлена (monomio) число спереди — coeficiente, буквенная часть — parte literal, сумма показателей букв — grado. Складывать и вычитать можно только monomios semejantes (с одинаковой буквенной частью и степенями).

Операции с многочленами (polinomios)

  • Suma y resta: приводим подобные слагаемые (reducir términos semejantes). Если перед скобкой минус — меняем знаки всех слагаемых внутри.
  • Multiplicación: каждый член первой скобки умножаем на каждый член второй; коэффициенты перемножаются, показатели степеней складываются (x² · x³ = x⁵).
  • Sacar factor común (вынесение общего множителя): обратная операция. В 6x³ − 9x² + 3x общий множитель 3x → 3x(2x² − 3x + 1). Заметь: на месте 3x остаётся 1, а не 0!
Ejemplo resuelto · операции с полиномами

Даны P(x) = 3x² − 5x + 2 и Q(x) = 2x − 1. Найти P(x) − 2Q(x) и P(x) · Q(x).

  1. P(x) − 2Q(x) = (3x² − 5x + 2) − 2(2x − 1) = 3x² − 5x + 2 − 4x + 2 = 3x² − 9x + 4.
  2. P(x) · Q(x) = (3x² − 5x + 2)(2x − 1) = 6x³ − 3x² − 10x² + 5x + 4x − 2 = 6x³ − 13x² + 9x − 2.

2. Las 3 identidades notables (формулы сокращённого умножения)

Три формулы, которые нужно узнавать мгновенно в обе стороны (и раскрывать скобки, и сворачивать):

(a + b)² = a² + 2ab + b²cuadrado de una suma
(a − b)² = a² − 2ab + b²cuadrado de una diferencia
(a + b)(a − b) = a² − b²suma por diferencia
Главная ловушка экзамена: (a + b)² ≠ a² + b²

Никогда не забывай удвоенное произведение ±2ab! Например, (x + 3)² = x² + 6x + 9, а не x² + 9. И второй момент: в (3x)² в квадрат возводится и число, и буква: (3x)² = 9x², а не 3x².

Ejemplo resuelto

Раскрыть скобки и упростить: (2x − 5)² − (2x + 1)(2x − 1).

  1. Первая скобка (квадрат разности): (2x)² − 2·(2x)·5 + 5² = 4x² − 20x + 25.
  2. Произведение (разность квадратов): (2x)² − 1² = 4x² − 1.
  3. Вычитаем в скобках: (4x² − 20x + 25) − (4x² − 1) = 4x² − 20x + 25 − 4x² + 1 = −20x + 26.

3. Ecuaciones de 1er grado con paréntesis y denominadores

Стандартный алгоритм решения линейного уравнения со скобками и дробями:

  1. Найти m.c.m. всех знаменателей и умножить на него каждое слагаемое обеих частей уравнения (включая целые числа без дроби!).
  2. Раскрыть скобки (quitar paréntesis), внимательно следя за знаками.
  3. Перенести слагаемые с x в одну часть, числа — в другую (transponer términos), меняя знак при переносе через «=».
  4. Привести подобные (reducir) и разделить на коэффициент при x (despejar la incógnita).
Ловушка: минус перед дробью

Дробная черта работает как невидимые скобки! Если перед дробью стоит минус, он относится ко всему числителю. Всегда ставь скобки при избавлении от знаменателей:

− 2x − 3/4 после умножения на 4 превращается в −(2x − 3) = −2x + 3 (знак перед тройкой поменялся на плюс!).

Ejemplo resuelto

Решить уравнение: x + 1/2 − 2x − 3/6 = 1 − x/3

  1. m.c.m.(2, 6, 3) = 6. Умножаем всё уравнение на 6: 3(x + 1) − 1·(2x − 3) = 6·1 − 2x.
  2. Раскрываем скобки: 3x + 3 − 2x + 3 = 6 − 2x.
  3. Переносим x влево, числа вправо: 3x − 2x + 2x = 6 − 3 − 3.
  4. 3x = 0 → x = 0. (Ноль — нормальное число и полноценный корень!).

4. Ecuaciones de 2º grado: completas e incompletas

Квадратное уравнение в стандартном виде записывается так (a ≠ 0):

ax² + bx + c = 0

Полные уравнения (completas: есть a, b и c)

Решаются через общую формулу корней и дискриминант Δ = b² − 4ac:

x = −b ± √(b² − 4ac)/2aΔ > 0 → 2 корня; Δ = 0 → 1 двойной корень; Δ < 0 → нет вещественных корней (sin solución real)
Ловушка со знаком b и b²

Если b = −5, то в начале формулы стоит −b = +5, а под корнем b² = (−5)² = +25 (квадрат любого вещественного числа в b² всегда положителен!).

Неполные уравнения (incompletas) — без формулы быстрее!

Тип 1 · c = 0 (ax² + bx = 0)

Выносим x за скобку (sacar factor común): x(ax + b) = 0. Один корень всегда x₁ = 0, второй x₂ = −b/a.

Пример: 3x² − 12x = 0 → 3x(x − 4) = 0 → x₁ = 0, x₂ = 4.

Тип 2 · b = 0 (ax² + c = 0)

Выражаем x² = −c/a и извлекаем корень со знаком ±.

Пример: 2x² − 18 = 0 → x² = 9 → x = ±3 (два корня: +3 и −3!). А у x² + 9 = 0 решений нет.

Ejemplo resuelto · completa

Решить уравнение: 2x² − 7x + 3 = 0.

Выписываем коэффициенты: a = 2, b = −7, c = 3. Дискриминант: Δ = (−7)² − 4·2·3 = 49 − 24 = 25.

x = (7 ± √25) / (2·2) = (7 ± 5) / 4 → x₁ = 12/4 = 3; x₂ = 2/4 = 1/2.

5. Sistemas de ecuaciones lineales 2×2

Система двух линейных уравнений с двумя неизвестными (x, y) решается любым из трёх классических методов — все дают один и тот же ответ:

МетодСутьКогда удобнее всего
Sustitución (подстановка)Выразить одну букву из одного уравнения и подставить во второе.Есть буква с коэффициентом 1 или −1.
Igualación (приравнивание)Выразить одну и ту же букву из обоих уравнений и приравнять правые части.Буква уже выражена или легко выражается в обоих уравнениях.
Reducción (сложение)Умножить уравнения так, чтобы коэффициенты при одной букве стали противоположными, и сложить строки.У всех букв коэффициенты отличны от 1 (самый быстрый и безошибочный метод!).
Ejemplo resuelto · три метода на одной системе

Решить систему: (1) 2x + y = 7 и (2) 3x − 2y = 7.

  1. Por sustitución: из (1) y = 7 − 2x. Подставляем во (2): 3x − 2(7 − 2x) = 7 → 3x − 14 + 4x = 7 → 7x = 21 → x = 3. Тогда y = 7 − 2·3 = 1.
  2. Por igualación: из (1) y = 7 − 2x, из (2) y = (3x − 7)/2. Приравниваем: 7 − 2x = (3x − 7)/2 → 14 − 4x = 3x − 7 → 7x = 21 → x = 3, y = 1.
  3. Por reducción: умножим (1) на 2: 4x + 2y = 14. Сложим со (2): (4x + 3x) + (2y − 2y) = 14 + 7 → 7x = 21 → x = 3, y = 1.

6. Sistemas 3×3 por el método de Gauss paso a paso

Método de Gauss превращает систему 3×3 в «ступенчатую» (sistema escalonado): во 2-м уравнении исчезает x, а в 3-м исчезают и x, и y. После этого неизвестные находятся снизу вверх (sustitución hacia atrás).

Ejemplo resuelto · метод Гаусса по шагам

Решить систему: E₁: x + y + z = 6, E₂: 2x − y + z = 3, E₃: x + 2y − z = 2.

  1. Опорная строка: в E₁ коэффициент при x равен 1 — идеально. Оставляем E₁ на первом месте.
  2. Убираем x из E₂ и E₃ (используя E₁):
    E₂' = E₂ − 2·E₁: (2x − y + z) − (2x + 2y + 2z) = 3 − 12 → −3y − z = −9 (или 3y + z = 9).
    E₃' = E₃ − E₁: (x + 2y − z) − (x + y + z) = 2 − 6 → y − 2z = −4.
  3. Убираем y из третьей строки (используя только 2-ю и 3-ю! E₁ больше не трогаем, иначе вернётся x):
    Поменяем местами E₂' и E₃', чтобы во 2-й строке стояло y − 2z = −4, а в 3-й 3y + z = 9.
    E₃'' = E₃' − 3·E₂': (3y + z) − 3(y − 2z) = 9 − 3(−4) → 7z = 21.
  4. Обратный ход (снизу вверх):
    Из 3-й строки: 7z = 21 → z = 3.
    Во 2-ю строку: y − 2·3 = −4 → y = 2.
    В 1-ю строку: x + 2 + 3 = 6 → x = 1. Ответ: (1, 2, 3).

7. Planteamiento de problemas и правки преподавателя в Envío U2

Любая текстовая задача решается в 4 шага: 1) выбрать и назвать неизвестные (definir las incógnitas), 2) перевести условия в уравнения (plantear), 3) решить (resolver), 4) проверить смысл ответа (comprobar e interpretar — например, ширина дорожки или длина стороны не могут быть отрицательными).

Ejemplo resuelto · рамка / дорожка вокруг прямоугольника

Бассейн 10 m на 6 m окружён дорожкой (pasillo / camino) постоянной ширины x. Общая площадь бассейна вместе с дорожкой — 140 m². Найти ширину дорожки x.

  1. Дорожка опоясывает бассейн с двух сторон по длине и с двух сторон по ширине! Поэтому внешние размеры: (10 + 2x) и (6 + 2x).
  2. Уравнение площади: (10 + 2x)(6 + 2x) = 140 → 60 + 32x + 4x² = 140 → 4x² + 32x − 80 = 0.
  3. Разделим на 4: x² + 8x − 20 = 0 → x = (−8 ± √(64 + 80))/2 = (−8 ± 12)/2 → x₁ = 2 m, x₂ = −10 (отбрасываем). Ответ: 2 m.
Внимание! Модификации преподавателя в Actividades de Envío U2

В файле заданий Envío U2 преподаватель изменил исходные числа (чтобы отсечь списывание со старых шаблонов). Обязательно решай именно с этими данными:

  • Задача про дорожку (pasillo): ширина дорожки равна 2 m (pasillo de 2 m). Помни, что с двух краёв она добавляет 2 + 2 = 4 m к каждому измерению!
  • Задача про телефонный тариф (llamada): стоимость минуты разговора — 0,24 €/min.
  • Задача про прямоугольник (largo y ancho): длина на 2 m больше ширины (el largo mide 2 m más que el ancho, т.е. если ширина x, то длина x + 2).

9. Проверь себя

Раскрой скобки: (3x − 4)² и (5x + 2)(5x − 2)
(3x − 4)² = 9x² − 24x + 16. (5x + 2)(5x − 2) = 25x² − 4.
Реши уравнение: (x + 2)/3 − (x − 1)/2 = 1
m.c.m.(3,2) = 6 → 2(x + 2) − 3(x − 1) = 6 → 2x + 4 − 3x + 3 = 6 → −x = −1 → x = 1.
Реши неполные квадратные уравнения: а) 4x² − 20x = 0; б) 3x² − 75 = 0
а) 4x(x − 5) = 0 → x₁ = 0, x₂ = 5. б) x² = 25 → x₁ = 5, x₂ = −5.
Реши полное квадратное уравнение: x² − 5x + 6 = 0
Δ = 25 − 24 = 1; x = (5 ± 1)/2 → x₁ = 3, x₂ = 2.
Реши систему: x + 2y = 8 и 3x − 2y = 4
Складываем уравнения (reducción): 4x = 12 → x = 3. Подставляем: 3 + 2y = 8 → y = 2,5.
Участок шириной x и длиной на 2 m больше окружён дорожкой шириной 2 m со всех сторон. Каковы внешние размеры участка с дорожкой?
Внутренние размеры: x и x + 2. Дорожка 2 m добавляет по 2 m с каждого края (всего +4 m): внешняя ширина x + 4, внешняя длина x + 6.
